# FileEditor iOS 6 Tweak

A simple Cydia tweak project for iOS 6 devices.

## Features
- File editing support
- Designed for jailbroken iOS 6 devices
- Built with Theos
- Objective-C / Logos based

## Target
- iOS 6.x
- ARMv7 devices (iPhone 3GS, iPhone 4, iPhone 4S)

## Files
- `Tweak.xm` - Main tweak code
- `control` - Cydia package information
- `Makefile` - Theos build settings

## Status
🚧 Development project

Made for learning iOS tweak development.
